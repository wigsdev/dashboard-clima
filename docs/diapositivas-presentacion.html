🎯 Diapositiva 2: Propósito, Problemática y Solución

📋 Necesidad del Proyecto (Sección 1)

  • Consulta Meteorológica: Necesidad de consultar en tiempo real las condiciones climáticas de cualquier ciudad del mundo.

  • Arquitectura en 5 Capas: Separación limpia entre Modelos, Servicios, Vista (UI) y Controlador Orquestador.

🌤️ Diapositiva 6: Clase Modelo `Clima` — Constructor y Encapsulamiento

💡 Encapsulamiento y Normalización

  • ¿Por qué una Clase Clima?: Desacopla la lógica interna del formato crudo de la API, encapsulando datos y comportamientos en una sola entidad.
  • Constructor: Normaliza tipos numéricos con Math.round() para temperatura, sensación térmica y viento.
  • Propiedades Esenciales: Almacena ciudad, país, temperatura, sensación térmica, humedad, viento, condición e ícono.
  • Integridad: Protege la interfaz contra valores null o formatos inesperados del proveedor.
js/models/Clima.js 
export class Clima {
  constructor({ ciudad, pais, temperatura, sensacionTermica, humedad, viento, codigoWmo, esDia = 1 }) {
    this.ciudad = ciudad;
    this.pais = pais;
    this.temperatura = Math.round(temperatura);
    this.sensacionTermica = Math.round(sensacionTermica);
    this.humedad = humedad;
    this.viento = Math.round(viento);
    this.codigoWmo = codigoWmo;
    this.esDia = esDia;

    // Traduce código WMO a texto e ícono SVG
    const infoWmo = Clima.mapearWMO(codigoWmo, esDia);
    this.condicion = infoWmo.descripcion;
    this.icono = infoWmo.icono;
  }
}

🌡️ Diapositiva 7: Métodos de Dominio y Conversión de Unidades

💡 Lógica de Negocio Encapsulada

  • toFahrenheit(): Conversión matemática precisa: (°C × 9/5) + 32 redondeada.
  • obtenerTemperatura(unidad): Devuelve la temperatura calculada según la unidad activa ('C' o 'F').
  • obtenerUbicacionCompleta(): Retorna la cadena compuesta "Ciudad, País".
  • esCalido(): Lógica de negocio que determina si la temperatura supera los 24 °C para estilizado visual.
js/models/Clima.js 
obtenerUbicacionCompleta() {
  return `${this.ciudad}, ${this.pais}`;
}

toFahrenheit(celsius) {
  return Math.round((celsius * 9 / 5) + 32);
}

obtenerTemperatura(unidad = 'C') {
  return unidad === 'F' ? this.toFahrenheit(this.temperatura) : this.temperatura;
}

obtenerSensacion(unidad = 'C') {
  return unidad === 'F' ? this.toFahrenheit(this.sensacionTermica) : this.sensacionTermica;
}

esCalido() {
  return this.temperatura >= 24;
}

static mapearWMO(codigo, esDia = true) {
  const iconoDespejado = esDia
    ? 'assets/icons/weather/clear-day.svg'
    : 'assets/icons/weather/clear-night.svg';
  const iconoParcial = esDia
    ? 'assets/icons/weather/partly-cloudy.svg'
    : 'assets/icons/weather/partly-cloudy-night.svg';

  const mapa = {
    0: { condicion: 'Cielo despejado', icono: iconoDespejado },
    1: { condicion: 'Mayormente despejado', icono: iconoDespejado },
    2: { condicion: 'Parcialmente nublado', icono: iconoParcial },
    3: { condicion: 'Nublado', icono: 'assets/icons/weather/cloudy.svg' },
    61: { condicion: 'Lluvia ligera', icono: 'assets/icons/weather/rain.svg' },
    95: { condicion: 'Tormenta eléctrica', icono: 'assets/icons/weather/thunderstorm.svg' }
  };
  return mapa[codigo] || { condicion: 'Condición variable', icono: iconoParcial };
}

📋 Diapositiva 9: Gestión del Historial de Búsquedas con Arreglos

💡 Justificación Técnica de Arreglos (`Array`)

  • ¿Por qué un Arreglo?: Es la estructura lineal óptima para almacenar colecciones ordenadas cronológicamente, permitiendo acceso por índice y mutación controlada.
  • Encapsulamiento del Estado: La propiedad interna this._ciudades mantiene la lista limpia de ciudades.
  • Inmutabilidad Externa: El método obtenerTodas() devuelve una copia con el operador spread ([...this._ciudades]) para proteger la lista original.
js/models/Historial.js 
export class Historial {
  constructor(limite = 5, storageKey = 'weather_dashboard_history') {
    this.limite = limite;
    this.storageKey = storageKey;
    this._ciudades = [];
    this.cargarDeStorage();
  }

  obtenerTodas() {
    // Retorna copia inmutable del arreglo
    return [...this._ciudades];
  }

  get total() {
    return this._ciudades.length;
  }
}

🔄 Diapositiva 10: Operaciones Inmutables y Deduplicación

💡 Métodos Funcionales de Arreglos

  • filter(): Elimina cualquier ocurrencia previa de la misma ciudad normalizando a minúsculas, garantizando **cero duplicados**.
  • unshift(): Inserta la ciudad recién consultada en la posición inicial (índice 0), otorgándole prioridad de más reciente.
  • slice(0, 5): Trunca estrictamente el arreglo al límite configurado de 5 elementos.
js/models/Historial.js 
agregar(ciudad) {
  const nombreLimpio = (ciudad || '').trim();
  if (!nombreLimpio) return;

  // 1. Filtrar duplicados previos (insensible a mayúsculas)
  this._ciudades = this._ciudades.filter(
    (c) => c.toLowerCase() !== nombreLimpio.toLowerCase()
  );

  // 2. Insertar al inicio de la lista
  this._ciudades.unshift(nombreLimpio);

  // 3. Mantener tamaño máximo de 5 elementos
  if (this._ciudades.length > this.limite) {
    this._ciudades = this._ciudades.slice(0, this.limite);
  }

  this.guardarEnStorage();
}

💾 Diapositiva 11: Persistencia Local con `localStorage` y Limpieza

💡 Persistencia entre Sesiones y Limpieza

  • JSON.stringify(): Transforma el arreglo de JavaScript a una cadena de texto para almacenarlo en localStorage.
  • JSON.parse(): Reconstruye el arreglo al iniciar la aplicación, protegido con bloque try / catch ante datos corruptos.
  • limpiar(): Vacía el arreglo interno en memoria y remueve la clave del almacenamiento web.
js/models/Historial.js 
guardarEnStorage() {
  try {
    localStorage.setItem(this.storageKey, JSON.stringify(this._ciudades));
  } catch (e) {
    console.warn('No se pudo guardar en localStorage:', e);
  }
}

cargarDeStorage() {
  try {
    const raw = localStorage.getItem(this.storageKey);
    this._ciudades = raw ? JSON.parse(raw) : [];
  } catch (e) {
    this._ciudades = [];
  }
}

limpiar() {
  this._ciudades = [];
  localStorage.removeItem(this.storageKey);
}

🌐 Diapositiva 12: Fundamentos de Promesas y Peticiones Asíncronas

💡 ¿Qué es una Promesa y cómo interviene?

  • Concepto: Objeto nativo de JavaScript que representa el resultado eventual de una operación asíncrona en red que tarda un tiempo indeterminado.
  • Ciclo de Estados: Inicia en Pending (pendiente) y finaliza en Fulfilled (resuelta) o Rejected (rechazada por fallo).
  • Naturaleza No Bloqueante: La petición HTTP no congela la interfaz del usuario ni el hilo principal de ejecución.
js/services/WeatherService.js 
// Demostración conceptual de Promesa nativa
fetch('https://geocoding-api.open-meteo.com/v1/search?name=Lima')
  .then((respuesta) => {
    if (!respuesta.ok) throw new Error('Error en el servidor');
    return respuesta.json(); // Segunda promesa de parseo
  })
  .then((datos) => console.log('Datos recibidos:', datos))
  .catch((error) => console.error('Fallo capturado:', error))
  .finally(() => console.log('Operación finalizada'));

⚡ Diapositiva 13: Flujo Asíncrono Secuencial con `async / await`

💡 ¿Qué hace `async` y `await`?

  • `async`: Declara una función asíncrona y envuelve automáticamente su valor de retorno en una Promesa.
  • `await`: Pausa la ejecución dentro de la función hasta que la Promesa se resuelva, permitiendo escribir código asíncrono con aspecto secuencial.
  • Ventaja Técnica: Elimina el anidamiento excesivo de .then() y permite capturar errores de forma limpia con try / catch.
js/services/WeatherService.js 
export class WeatherService {
  async consultarClima(nombreCiudad) {
    // 1. await espera la respuesta de geocodificación
    const resGeo = await fetch(urlGeocoding);

    const dataGeo = await resGeo.json();

    // 2. await espera la respuesta meteorológica
    const resClima = await fetch(urlForecast);
    if (!resClima.ok) throw new Error('Error al consultar pronóstico');
    const dataClima = await resClima.json();

    return new Clima({ ... });
  }
}

mostrarCargando(visible) {
  if (!this.loadingSpinner) return;
  this.loadingSpinner.classList.toggle('hidden', !visible);
  if (this.btnSearch) this.btnSearch.disabled = visible;
  if (this.searchInput) this.searchInput.disabled = visible;

    this.ocultarError();
    if (this.weatherContainer) this.weatherContainer.classList.add('hidden');

}

mostrarError(mensaje) {
  if (!this.errorCard || !this.errorMessage) return;

  this.errorCard.classList.remove('hidden');

renderizarHistorial(ciudades = []) {

  • Evento submit: Al asociarse al formulario <form>, captura automáticamente tanto el clic en el botón como pulsar la tecla **Enter**.
  • e.preventDefault(): Anula el comportamiento estándar del navegador de recargar la página.
  • Validación de Campo Vacío: Cumple estrictamente el Requisito 2.A mostrando advertencia sin enviar peticiones innecesarias.
js/app.js 
if (this.ui.searchForm) {
  this.ui.searchForm.addEventListener('submit', (e) => {
    e.preventDefault(); // Evita recargar la página
    const ciudad = this.ui.searchInput ? this.ui.searchInput.value : '';
    this.buscar(ciudad);
  });
}

async buscar(ciudadTexto) {
  const ciudad = (ciudadTexto || '').trim();

  // Validación según Sección 2.A del Enunciado
  if (!ciudad) {
    this.ui.mostrarFeedback('⚠️ Introduce una ciudad para realizar la búsqueda.');
    if (this.ui.searchInput) this.ui.searchInput.focus();
    return;
  }

  this.ui.ocultarFeedback();
  await this.ejecutarConsulta(ciudad);
}

🖱️ Diapositiva 21: Delegación de Eventos en Historial y Toggle de Unidades

💡 Optimización con Delegación de Eventos

  • ¿Por qué Delegación?: Un solo listener en el contenedor #history-list atiende clics de chips presentes y futuros, reduciendo el consumo de memoria.
  • event.target.closest(): Detecta con exactitud si el clic ocurrió dentro de un chip y extrae el atributo dataset.city.
  • Toggle °C / °F: Recalcula instantáneamente la temperatura del clima actual sin realizar peticiones redundantes a la API.
js/app.js 
// Delegación de eventos en historial
if (this.ui.historyList) {
  this.ui.historyList.addEventListener('click', (e) => {
    const chip = e.target.closest('.history-chip');
    if (!chip) return;

    const ciudad = chip.dataset.city;
    if (ciudad) {
      if (this.ui.searchInput) this.ui.searchInput.value = ciudad;
      this.buscar(ciudad); // Re-consulta inmediata
    }
  });
}

// Alternador dinámico de unidades
cambiarUnidad(nuevaUnidad) {
  if (this.unidad === nuevaUnidad) return;
  this.unidad = nuevaUnidad;
  localStorage.setItem('weather_unit', nuevaUnidad);

  if (this.climaActual) {
    this.ui.renderizarClima(this.climaActual, this.unidad);
  }
}

🛡️ Diapositiva 22: Orquestación Global y Flujo `try / catch / finally`

💡 Integración del Flujo Asíncrono

  • try: Inicia el estado de carga, llama a WeatherService, renderiza en el DOM y actualiza el historial persistente.
  • catch: Captura cualquier fallo de red o ciudad inexistente y lo delega a la UI para feedback visual amigable.
  • finally: Garantiza incondicionalmente que el spinner de carga se oculte al terminar la operación.
js/app.js 
async ejecutarConsulta(nombreCiudad) {
  try {
    this.ui.mostrarCargando(true);

    // 1. Invocar Servicio Asíncrono
    const clima = await this.weatherService.consultarClima(nombreCiudad);
    this.climaActual = clima;

    // 2. Renderizar Clima en el DOM
    this.ui.renderizarClima(clima, this.unidad);

    // 3. Actualizar Historial y Almacenamiento
    this.historial.agregar(clima.ciudad);
    this.ui.renderizarHistorial(this.historial.obtenerTodas());

  } catch (error) {
    this.ui.mostrarError(error.message);
  } finally {
    // Apagado garantizado del spinner
    this.ui.mostrarCargando(false);
  }
}
